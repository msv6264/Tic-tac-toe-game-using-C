TIC TAC TOE GAME
The game is designed to have fun using c program
The UI of board is like code.

HOW TO PLAY GAME:
- Player 1 should chose a symbol either 'X' or 'O'.
- Player 1 gets chance to enter a symbol and the code wont accept symbols other than X or O .
- Players should enter the row and column numbers as well as symbol with space seperated.
- After each player plays the board gets updated and displayed.
- The winner is diclared if one wins.
- If no one wins, it shows "game is draw".
